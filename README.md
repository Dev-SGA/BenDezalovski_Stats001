# Ben Dezalovski — Stats de Jogo

App Next.js (Vercel) para exibir estatísticas individuais de **Ben Dezalovski** (Club Ohio) durante um jogo.

Estrutura inspirada no repositório *Training Development Report*, com visual próprio (tema escuro, tipografia Bebas Neue + Outfit).

## Desenvolvimento

```bash
npm install
npm run dev
```

Abra [http://localhost:3000](http://localhost:3000).

## Dados

Edite `data/gameStats.json` para atualizar números, links de vídeo e Top Connections (`topConnections`).

## Deploy

Conecte o repositório na Vercel; o `vercel.json` já define o framework Next.js.
